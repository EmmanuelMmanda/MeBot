# MeBot 0.9.4 — your notes, a fresher feed

Published 26 October 2026. The official Android update is available for `mebot.nguli.com`.

## What’s improved

- Confirm a context import and return to your details with the imported notes in view.
- Keep your draft when you cancel the review or need to correct a file.
- See a fresher feed: expired forecasts and events leave the active list, while saved items, starred stories and useful older reading remain available.
- Let your selected AI help match public stories to your interests during the existing feed refresh. This is optional guidance, not a promise about which stories will appear.

Your saved items, starred stories and personal notes remain yours. AI is optional; cached reading, public sources and local tools continue to work without it.

Import still asks you to review before replacing your profile and context notes. An import with no module settings keeps your current module choices. Updating from MeBot 0.9.0–0.9.3 installs over the existing app; do not uninstall or clear app data.

The APK, matching source, checksum list, release metadata and technical verification report are attached separately to the [official release](https://github.com/EmmanuelMmanda/MeBot/releases/tag/v0.9.4). The verification report contains test counts, signing details and limits that are intentionally separate from these user-facing notes.
