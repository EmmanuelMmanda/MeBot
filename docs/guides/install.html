Install & first launch

Install MeBot, connect ChatGPT or continue with public feeds, and decide whether to add personal context.

In the appDownload → Install → Open MeBot

Before you install#

MeBot runs on Android 8.0 or later. Use the public APK linked from the download page. The latest public APK includes story questions and Original Read. Existing users can check You → Software Updates for a compatible update.

No AI account is required for alarms, Focus, daily check-in, saved local records, or the available public-source adapters. Connected AI enables most personalized discovery, story explanations, search, and conversations.

Already have MeBot?

Install a compatible signed update over the existing release. Do not uninstall as an update step: uninstalling can remove local app data. Export important data first if you need a separate copy.

Install the APK#

  1. Download the APK to your Android phone from the official release page.
  2. Open the downloaded file. If Android asks, allow Install unknown apps for the browser or file manager you are using. The exact wording varies by phone.
  3. Confirm installation, then open MeBot. You may switch that installer permission off afterward.
  4. For an update, confirm that Android offers to update the existing release. A signing-key conflict or a lower version cannot be fixed by repeatedly trying the same file.

The production package is mebot.nguli.com. A compatible update must preserve the signing identity and have a higher version code; verify the published release before installing. Older separately installed builds may use a different signing identity; Android will reject an incompatible update rather than merge the apps.

See installation troubleshooting if Android rejects the file.

The first launch#

With ChatGPT, first-run setup guides you through three stages: connect for AI guidance, optionally add context you choose, then start your feed. If you prefer not to connect, continue directly with public feeds. Choose English or Kiswahili; change the language later under You → Personalization → Language.

  1. Tap Set up my feed, then choose Continue with ChatGPT to connect and verify your account. Or choose Continue with public feeds to open the feed without AI setup. Other provider routes remain under You → AI connection.
  2. After connecting ChatGPT, choose Add personal context if you want to continue. On that screen, select Choose feed topics, import reviewed JSON, or write a note in MeBot. You can skip the step and add context later from You → About you.
  3. Choose Start my feed. Then select the modules and topics you want to follow.

Find your way around#

DestinationWhat you do there
FeedRead updates, filter modules, search, and open stories. Tap Feed again to return to the top and refresh.
ModulesBrowse the full catalog, edit preferences and order, and open everyday tools.
AIAsk a question, continue a thread, or start with a module’s context.
SavedReturn to stories you saved, including items from paused modules.
YouManage the AI connection, personal context, background requests, FAQs, preferences, and data.

Changing a filter does not make an AI request. Use Show more to reveal cached stories as you need them.

Give access when a feature needs it#

MeBot asks for feature-specific access rather than requiring every phone permission at launch. Alarm setup links to exact timing, notifications, and lock-screen access. A QR alarm needs the camera; selecting your audio uses Android’s file picker. Weather uses a place you enter and does not request GPS.

For your first alarm, complete the phone setup and short locked-screen test. Android scheduling, volume, Do Not Disturb, and manufacturer battery settings affect actual ringing.
