What changes in 0.8.4

01

A star beside the bookmark

Tap the star to follow a story. Tap the bookmark to save it. The star stays an icon: no extra label, follow-up panel or manage button on the feed card. Open Saved → Following when you want to manage cadence or pause a follow-up.

These remain separate actions. Follow-ups still use normal feed refresh and your existing request allowance; new coverage is not guaranteed.

02

Give media the full screen

Open supported image and media previews in a fullscreen viewer, with an explicit close action and a route back to the original source. Images, direct video and audio use the app’s fullscreen controls. For YouTube, use its own player fullscreen control; the same player stays active in the native shell.

Quality, captions, seeking and other controls depend on the source and the player. MeBot does not invent a quality selector when the source offers none. Some providers restrict embedding or playback; use the original source when needed. Availability still depends on connectivity and the provider.

03

Finish the tour, then start reading

Completing onboarding takes you straight to the feed, rather than immediately opening a second guide. You can replay the quick guide from Help whenever you need it.

The guide now explains save versus follow and source-dependent fullscreen controls in English and Kiswahili. The library’s empty-state guidance matches the selected Saved or Following tab, and its search label describes what can actually be searched.

Release history and verification

The 0.8.3 foundation passed 817 automated tests and built both APK variants. It is preserved as a tested candidate, not a signed official release. The separate 0.8.4 gate passed 829 tests (181 core, 479 Android and 169 service), with zero failures, errors or skips. Both APK variants built. Lint reported zero errors, 215 debug warnings, 216 release warnings and one hint per variant.

Native preview images demonstrate layout with controlled test content. They do not establish live account authorization, real streaming, device installation, notification delivery or overnight alarms. Device speech input and installed-voice read-aloud remain distinct from full-duplex realtime voice.
