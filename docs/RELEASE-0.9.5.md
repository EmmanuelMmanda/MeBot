# MeBot 0.9.5 — a useful next step for each story

Published 26 October 2026. MeBot 0.9.5 is the current official Android release for package `mebot.nguli.com`.

## What changed

- Open stories in MeBot first, with the publisher clearly shown.
- Recognize what a story covers from a compact, item-grounded category label.
- Explore suggested questions in Feed, story details and MeBot.
- Review or edit each story-specific question before deciding to send it. Choosing a suggestion never sends a request automatically.
- Open the original source directly from story details or the card menu whenever you want.

Connected-AI questions are reused only when they are suitable for the current story and approved context. Local questions remain available offline. Suggested questions complement, not replace, the publisher’s source.

## Updating

MeBot 0.9.5 retains production package `mebot.nguli.com` and the existing 0.9.x signing identity. Install over an existing production 0.9.0–0.9.4 app; do not uninstall or clear data. Older 0.8.x installations use a different package/signer lineage and are not an in-place update path.
