# Install or update MeBot 0.9.3

Download **mebot-0.9.3.apk** from the [verified release page](https://github.com/EmmanuelMmanda/MeBot/releases/tag/v0.9.3). Android 8.0 or later is required. This corrects the external file-picker and notification-permission launch crash in 0.9.0–0.9.2.

## Updating from 0.9.0, 0.9.1 or 0.9.2

Open the downloaded APK and let Android update your existing MeBot installation. These releases use the same production signing certificate. **Do not uninstall MeBot or clear its data to update.** The public APK was verified with the installed updater’s version/package/signing path; this is not a physical-phone or OEM picker acceptance claim.

## Earlier installations

0.8.x used an earlier signing certificate, so Android will not accept 0.9.3 as an in-place update to those binaries. Back up supported personal preferences before considering a different installation. Portable exports do not include protected credentials or app-lock secrets. Never erase the existing app simply to try an update. The old `app.mynguli` package is separate from `mebot.nguli.com`.

## First use

Choose your language and interests, then explore the feed. AI connection is optional for public information and local tools. Reconnect accounts when needed and test configured alarms on your phone.

**You → Software Updates** checks for compatible official releases and verifies downloaded files before Android asks to install. Automatic checks are separate from AI and can be configured.
