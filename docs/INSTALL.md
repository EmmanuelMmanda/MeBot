# Install MeBot 0.8.2

Use the official APK on the [versioned release page](https://github.com/EmmanuelMmanda/MeBot/releases/tag/v0.8.2). The new package is **mebot.nguli.com**, a fresh install rather than an in-place update to earlier development builds. Reconnect accounts, choose interests and test alarms. Your older test data can be exported when needed, but protected credentials and system alarm registrations do not transfer automatically.

For future same-package releases, **My MeBot → Software Updates** checks for compatible official versions and verifies downloaded files before Android asks to install. Automatic checks are separate from AI and can be configured.

[Start Here](../START-HERE.md) gives the visual first-use journey. [User Guide](USER-GUIDE.md) describes providers, usage, feedback, background operation, files and data controls. [Build Guide](BUILD.md) covers source builds and signing.
