Install without disturbing your existing app

  1. Open the APK on your Android phone. Allow installation from that browser or file manager when Android asks.
  2. Choose Update when replacing original official MeBot. Its package and signing certificate match.
  3. Open MeBot. Existing official-app settings stay in place. A fresh install starts with the interest-based setup.
  4. Using the earlier MeBot Test? It remains separate. Export and review any preferences you need in MeBot; reconnect accounts if needed.

Keep only the alarms you intend to use enabled across the two apps. Test sound and alarm delivery on your phone before relying on them overnight.
