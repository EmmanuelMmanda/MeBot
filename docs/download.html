Updating an existing installation
Install a compatible signed release over the existing app. Keep its data; uninstalling is not a routine update step. A different signing key or a lower version cannot replace the installed release. Debug builds install separately.
Export important context or backups if you want a separate copy, then follow the install guide. Test alarms on the actual phone after an update. Public APKs do not carry a personal starter profile or a shared API key.
Verify the file you received
Compare the downloaded APK’s SHA-256 with the published value above or the release’s integrity record. A matching hash checks that you have the intended file; it does not prove a live provider connection or overnight alarm behavior.
Compute a SHA-256 hash
sha256sum mebot-0.6.1.apk
On Windows, use Get-FileHash .\mebot-0.6.1.apk -Algorithm SHA256. The public artifact notes explain the clean distribution and source provenance.
