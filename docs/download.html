What the verification covers

The page validates GitHub’s published release, its matching APK asset, asset state, size, SHA-256 digest and release URLs. In-app update checks also validate the installed package and signing certificate before installation. Automated tests and host screenshots do not establish live provider access, physical-phone playback, biometric behavior, OEM file-picker support, or overnight alarms.
