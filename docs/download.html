Install or update

  1. Download and open the APK on Android. Allow your browser or file manager to install when Android asks.
  2. For existing 0.9.x installations, install over MeBot. Your package and signing identity match; keep the app installed and do not clear its data.
  3. On first install, choose your language and interests, then explore the feed. Importing a context file is optional.
  4. Connect an AI provider when ready. Public-source reading, saved items and local tools do not require an AI account.
  5. For future releases, open You → Software Updates. The installer verifies the package, version, bytes and certificate; Android still asks before installation.

Earlier 0.8.x binaries used a different signing identity; they are not an in-place update path to this release. Back up supported preferences before changing installation. Protected credentials do not transfer in portable exports. Do not erase your current app to try an update.
