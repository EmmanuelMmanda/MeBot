First installation with the new identity

  1. Open the downloaded APK on Android. Allow your browser or file manager to install when Android asks.
  2. Open MeBot, choose your language and interests, then explore your feed.
  3. Connect an AI provider when ready. Public-source information and daily tools do not require an AI account.
  4. For future releases, open My MeBot → Software Updates. Automatic checks are available; Android asks before installation.

The previous development package remains separate. Accounts, protected credentials and system alarm registrations do not automatically transfer. Reconnect accounts and test any alarms you configure. Export old personal preferences only when you need them.

What has and has not been tested

See the verification report for exact test counts, lint findings and signing checks. Automated provider responses and Android host tests are not substitutes for a real account login, physical-phone media, save-picker or overnight alarm testing.

Software Updates verifies the trusted release, downloaded bytes, package, version and certificate. It does not bypass Android installation approval. API keys have separate provider billing; subscription access remains subject to eligibility and limits.

Optional preferences import

Onboarding interests are enough to start. Later, use Copy starter prompt with your preferred assistant, then import or paste its JSON and review the changes.
