# MeBot 0.9.9

- Start with a short ChatGPT connection guide, add your own context, and continue to a personalised feed. Manual notes and JSON imports both work.
- Open prepared AI questions for the item or conversation you are reading. Load more distinct questions, send one, or edit it before sending.
- Follow an item with the star button and see confirmation of what changed. Opportunity cards show a source-backed closing date when one is available.
- Select, copy and share answers, copy code separately, and use clearer read-aloud controls.
- See optional setup reminders based on what is actually configured. Voice recording and call controls appear only when their required capability is available; ChatGPT text sign-in does not include separately billed API voice.
- Keep local voice drafts under your control, with explicit transcription consent and cleanup when discarded or local data is erased.
- Keep Today’s selections current when item details or their language change.
