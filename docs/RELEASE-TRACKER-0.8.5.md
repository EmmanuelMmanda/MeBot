## Product direction

Keep MeBot's existing typography, colour roles, rounded controls and five-destination navigation. Prioritize useful content over introductory panels: concise headings, a single editable personal profile, horizontally scrolling topic filters and a clear Saved/Following hierarchy. Maintain 48dp action targets, localized English/Kiswahili copy, large-text wrapping and durable user input. Examples are optional help, never automatically saved personal facts.

### Observed cancellation-test timing

The post-merge 0.8.4 Android CI rerun failed an immediate TCP-refusal assertion after cancellation, while the same application source had passed the local and pull-request gates. The exact failing assertion was recovered from its test XML. An isolated JDK 17 reproduction observed 4 successful immediate TCP handshakes in 3,000 close/accept races and none after the accept thread had exited. This is evidence about that specific kernel/JDK transition, not proof that all intermittent failures are resolved.

The 0.8.5 test now requires refusal within two seconds, with a 50 ms connect timeout, and checks that a stale callback is never acknowledged, no token exchange occurs, cancellation leaves idle state, and the next attempt uses fresh state/nonce/PKCE values with the same host identity. A separate 25-cycle regression exercises these invariants. Production authentication code is unchanged. All 30 authentication tests, including the 25-cycle stress regression, passed in both the focused and full gates.
