# Jobs native capture record

These are unmodified, visually reviewed native Android captures of 0.10.1-debug, not illustrations or production account data. All vacancies, employers, notes and drafts are synthetic device-test fixtures. No live AI request or employer submission was made.

The [manifest](../../assets/jobs-screens.json) records exact source, tested merge, APK and individual PNG SHA-256 digests, dimensions, locale, theme and capture method. The isolated Android API 36.1 emulator passed three instrumented journeys in each of phone light, phone dark with 1.5× text, and tablet light (nine tests total).

The shortlist image is an additional settled native screenshot after scrolling, from the same APK. Other images are instrumented journey captures. The original tablet detail capture had a stale compositor frame and is deliberately not included. No images have been cropped, composited or retouched.

The saved-draft frame demonstrates persistence after reopening, not export completion. The AI frame demonstrates disconnected context review, not a generated response. Dates within screenshots are synthetic test state. These captures describe the tested debug build; the download page remains the authority for the latest published release.
