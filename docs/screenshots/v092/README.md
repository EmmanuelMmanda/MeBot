These are the actual MeBot Activity and theme rendered on an Android host test at 411dp/default font scale, not image-generation mockups or isolated unthemed controls. They use synthetic fixtures and no owner accounts, PIN or private data. The renderer uses the debug test variant; the delivered APK is separately built and verified as signed, non-debuggable production.
