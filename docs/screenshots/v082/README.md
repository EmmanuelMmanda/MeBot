# MeBot 0.8.2 screen captures

These are native Android/Robolectric host renders of the actual Compose UI, captured on 25 October 2026. They are not photographed devices or authenticated production account sessions. They may show the debug build suffix because UI verification uses the debug host.

Public editorial inputs are retained with source, retrieval timestamp and image credit in [the capture manifest](../../captures/v082/sources.json). Article text has been briefly paraphrased. Provider streaming, update availability and account states are controlled for repeatable UI tests; these captures do not prove live subscription eligibility, current vacancies or physical-phone behavior.

All current gallery screens are from 0.8.2. The Dar es Salaam photograph is historical, not a live location image. NASA imagery and the city photograph have their own documented credits. Publisher images appear only in attributed editorial screenshots and are not bundled as general-purpose application assets. [Image credits](../../IMAGE-CREDITS.md).
