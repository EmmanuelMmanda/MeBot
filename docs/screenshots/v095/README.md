# 0.9.5 native UI sample captures

These ordinary-size full-activity captures are native Android host-test images from the published MeBot 0.9.5 build. Feed and detail views are intentionally scrolled to the suggested-question area; MeBot shows the prepared editable draft before Send.

All story titles, publishers, provider responses and preferences are synthetic test fixtures. They are not live articles, an owner account, a provider round trip or physical-phone acceptance evidence. English story fixture text remains English in the Kiswahili UI captures. The selected provider/model label is fixture configuration, not a statement that a subscription or live model was tested. Selecting a suggestion prepares the draft; it does not send a request.

- `en-feed.png`, `sw-feed.png`: item-grounded question alongside the existing feed controls.
- `en-detail.png`, `sw-detail.png`: the original source remains available as a secondary action, with the suggested question in view.
- `en-mebot-prefilled.png`, `sw-mebot-prefilled.png`: editable item-scoped question shown in MeBot before Send.

User-facing galleries label these as sample content. Narrow-layout accessibility stress captures are separate. These images do not establish a live provider response or real-device acceptance; check the release directory for exact release assets.
