# MeBot 0.7.1 native screen examples

These images are rendered by `MeBotPolishUiTest` from the actual Compose UI on the
Android 35 Robolectric runtime. Content and account labels are synthetic examples.
They are not live AI replies, real downloaded documents or physical-phone captures.

- `mebot-0.7.1-streaming.png`: the one fixed top activity surface during an answer.
- `mebot-0.7.1-ai-resources.png`: a completed answer with Sources, Media and Files.
- `mebot-0.7.1-appearance.png`: accent/custom color and page-style controls.
- `mebot-0.7.1-detail-files.png`: story source tab with a directly saveable PDF card.

The screen layout is unchanged by the examples. Original resource links remain
available if a publisher does not support a preview or direct download.
