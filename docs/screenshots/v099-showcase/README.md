# Showcase capture record

**Status:** candidate screenshots prepared in a local qualification build; this is not a release announcement. The website download link continues to come from `docs/assets/release.json`, which remains the latest published release until that manifest is deliberately updated after release approval.

## Capture method and limits

- Native full-shell Android UI captures at **411 × 891 dp / 822 × 1782 px**, rendered with Robolectric and captured as PNG via PixelCopy. The Appearance settings capture is a separate **822 × 1212 px native dialog-window PixelCopy**. Every file is copied byte-for-byte; no crop, color treatment, or retouch was applied.
- The activity uses `FeedTestApplication` with a deterministic in-process fake AI provider and checked-in fixture text. No network request, paid AI call, live provider session, or real user account produced these responses. The `gpt-6-luna` model label in the editable-draft screen is synthetic test UI state.
- The question-sheet views capture the real Activity and Compose dialog windows at their on-screen positions to reproduce the displayed Android screen. The `Generated by AI` label reflects the fixture pipeline only.
- The feed example keeps background delivery off. The optional background tip is dismissed through its actual **Later** action; this does not enable background scheduling or notifications.
- The About You profile name and region are blank. The displayed interest note is generic sample data, scoped to News, Opportunities, and Tech & AI.
- The full-screen Appearance capture that exposed a debug footer is withheld. The included dialog-only Appearance screen shows the actual accent and page-style choices with no footer/debug text; full-shell light and dark renders separately show app themes.
